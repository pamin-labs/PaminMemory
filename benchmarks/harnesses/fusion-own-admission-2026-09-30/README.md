# Inert native own-corpus source evidence

These .in files are archival templates, outside Cargo discovery. They preserve the actual 157 query native acceptance test, its public 230 memory fixture, all sibling native modules it imports (including nested reranking/router), native scoring/statistics, frozen baseline/pooled engine source and candidate pool, Cargo manifests/locks, historical controllers and initial failed harness. No test/default/product file is changed by this package.

Base revision is 13ee710c9df865f1dac98dc77a8108e438ddc539. Source overlays are recorded in the linked result sources.json. Only baseline versus pooled engine EXPERIMENTAL_CHANNEL_POOL differs; candidate-toggle.patch.gz is the corresponding source-only unified diff. Both retain graph threshold 0.5/cap 30 and private literal false/true. The complete frozen engine files show the call path; other product dependencies are public repository files at the named revision. Archived sibling modules make the scratch native test self-contained within its test directory, not a standalone replacement for the product workspace.

To reconstruct source in a disposable clone at that revision: restore workspace-Cargo.toml.in to Cargo.toml, the chosen arm's Cargo.lock.gz to Cargo.lock, chosen arm/Cargo.toml.in to crates/pamin-engine/Cargo.toml, and chosen arm/src/*.rs.in to crates/pamin-engine/src/*.rs. Copy tests/** preserving directories and strip .in from Rust filenames into crates/pamin-engine/tests/. The test target becomes scratch_pool_retrieval.rs, with original native corpus/memories.json and queries.json in tests/corpus. Never copy the initial failed harness over the successful target. The native-statistics.rs.in archival driver originally imported an absolute scratch statistics module; replace that #[path] with the restored local tests/statistics/mod.rs before any optional compilation. Its exact 157-ID input vectors are independently checked by the Python verifier.

Compressed historical controllers are retained as evidence, not safe future launchers. Their path aliases require local substitution, they inherit incompletely recorded tuning, and their assertions lack an optimization guard. Do not run them as default certification. A future runner must reject inherited unknown PAMIN settings before build/run, capture explicit effective settings, use fresh dedicated stopped clones and prospectively bind complete source/toolchain/lockfile/build outputs/binaries/config. Source templates and original compiler logs alone cannot provide that historical attestation.

The present package and verifier require no compilation, models or databases. Reconstruction instructions describe source only; no model execution is authorized or performed by verification. Original test hashes/binary identities, sanitized build/compiler logs, configuration UNKNOWN and observed flat-buffer coverage 0 remain in the [results](../../results/fusion/own-admission-2026-09-30/README.md).
